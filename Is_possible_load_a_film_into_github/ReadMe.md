# I thing that the answer could be yes, but using this workaround!

## How I've converted the uploaded videos

### Program used

- [7z](https://www.7-zip.org/)

### Settings 

After adding the video to the 'add to archive' utility, I compressed and split the video using these settings:

- Archive format: 7z
- Compression level: Ultra
- Compression method: LZMA2
- Dictionary size: 64MB
- Word size: 64
- Solid Block size: 4GB
- Number of CPU threads: max
---
- Split to volumes. bytes: 10M
---
- The rest of the options: must be left as they are, without changing any settings

Menelli Box PowerGlove Interface

The "Menelli Box" is a serial interface for the PowerGlove. It takes care of polling the glove to produce the x, y, z and roll data, packages the data up into a packet and sends it out on a standard RS-232 serial port.

A local archive of useful PC software for use with the menelli box is available.

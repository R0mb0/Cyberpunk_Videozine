




This file is created as an attempt to help all new HST users set up the
modems for BBS data transfer.

It is assumed that the user is using Telix 3.11 and the HST supports 38400.
No attempt will be made to explain these various settings as it is all covered
in the documentation that comes with the modem. Using these settings I can
consistently download at 1700 to 1750 cps.

Use YMODEM-G in ProDoor for best results.  Any of the -G protocols can be used
with good results.  You can also use ZMODEM it will be a little slower, but will work fine.

You should also replace the large chip on your COM port with a ns16550an chip.

Back switches on HST:
1 up
2 up
3 down
4 up
5 down
6 up
7 up
8 down
9 up
10 up

Enter telix
Enter alt O and set the baud rate for 2400 baud

Enter telix terminal and enter the following:
AT X6 &B1 &H1 &K3 &W

Note: if you do not have the V42.BIS chip installed
      use the above modem string except substitute
      &K0 for &K3.

The modem should respond with ok.

Enter alt O and select terminal options:
Set the baud rate for 38,400
Set xon/xoff software flow to off
Set cts/rts flow on
set dst/dtr flow off

Enter modem configuration:
Make sure autobaud detect is set to off.

Make sure that you set 38400 in your dialing directory for those numbers
you intend to use for connecting to other HST'S.

Your init string in the modem setup should be ATZ^M

I hope that this is a help to new HST users and if anyone knows of a better
setup please contact me.

                                MOUSE USAGE

BOTH BUTTONS:  Press both buttons to send ESCape.
---------------
RIGHT BUTTON:  Press the right button to display the main mouse menu.
               whenever you are not within any of Telix's menus, the 
               right button will display the main mouse menu.

               DIALING MENU:   Within the dialing menu, the right 
                               button will MARK an entry.

               OTHER MENUS:    Within all other Telix menus, the 
                               right button sends ESCape.
---------------
LEFT BUTTON:   Press the left button to send ALT-D.  The left button
               will then send ENTER.  When you are not in any of
               Telix's menus, the left button will send ALT-D for the
               DIALING menu.  Press the right button to ESCape. Or
               press the left button a second time, to go to the
               DIALING menu.

               DIALING MENU:   Within the dialing menu, the left 
                               button will display a line of options
                               at the bottom of the screen.  Move the
                               mouse left and right to highlight an
                               option.  Press the left button to 
                               select the option.
               OTHER MENUS:    Within all other Telix menus, the left
                               button sends ENTER.
---------------
MOUSE MOVES:   Mouse movements will do nothing unless you are within 
               a Telix menu.  Only the Telix menus that allow arrow
               key entry support mouse movement.  Move the mouse left and
               right, or up and down to send the arrow keypresses.

               DIALING MENU:    Move the mouse up and down to select
                                BBS entries.   Left and right 
                                movements will NOT register.  Press
                                the right button to MARK an entry.
                                Press the left button to select an
                                option at the bottom of the screen.

               OTHER MENUS:     Other Telix menus which allow arrow
                                keys support mouse movement.



                                MAIN MOUSE MENU

        The main mouse menu has all the main menu selections of TELIX
except the DOORWAY mode.  Move the mouse left, right, up and down to
highlight the selections.  Press either the right OR left buttons to
select an option.  To exit the main mouse menu without selecting an 
option, press both buttons.  Additional options are available at the 
bottom of the main mouse menu.

                                TIPS FOR USAGE

        Use the left button to select highlighted options on the main 
mouse menu.  Even though the right button will also select an option, 
use the left button instead to make your button use easier to remember.

        Use both buttons to ESCape from the DIALING menu.

        Use the right button to ESCape from all other Telix menus.

        Use the left button when you are ONLINE to send ENTER to
        the BBS.

        Click the left button twice to go directly to the DIALING 
menu.  This procedure works when you are not within any Telix menus.

        Press the left button to turn off the Telix screen when it 
first loads (shareware version only).

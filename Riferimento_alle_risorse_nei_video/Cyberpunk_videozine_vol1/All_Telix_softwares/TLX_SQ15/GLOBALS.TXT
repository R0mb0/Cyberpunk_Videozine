Global definitions currently used in the Telix_Square package.
;
; Globals to set in the NAME.DAT file:
;
NAME:   Your name.
ADDR:   Your address.
MAIL:   Your postal code and city.
STATE:  Your country.
HTEL:   Home phone number.
WTEL:   Your work phone number.
DPASS:  You "default" password.
WORK:   Your profession.
MODEM:  Current modem.
MAXB:   Your modem's max. baud rate.
CPU:    Your computer model
GRAPH:  YES/NO if you want/do not want graphics.
MDIR:   Mail Download directory.
MAXUP:  Max. no. of upload files per session.
MAXDN:  Max. no. of download files per session.
TAGA:   First tagline.
TAGB:   Second tagline (all but PCB systems)
TAGC:   Second tagline (only PCB systems)
;
; Globals defined internally. Some may also be predefined here:
;
LOGOF:  YES/NO if you want/do not want automatic logoff.
EXIT:   YES/NO if you want/do not want automatic exit (default: NO).
GRAB:   YES/NO if you want automatic mail grab (default: YES)
PASSW:  Your current password.
FPASS:  Default password for file download
BNAME:  Name of current BBS.
SHORT:  "Short" name of current BBS.
FILIST: Name of the file list for the current BBS.
BTYPE:  Type of current BBS.
CNAME:  Codename of current BBS.
CONF:   Current conference.
CPROT:  Current protocol.
PROMPT: Current command prompt.
PCBVER: PCB version number times 10.
DSZ:    DSZ parameters as specified in NAME.DAT.
CHANGE: Defined if display parameters changed.
f1 - f12: Default setting of f1 to f12 function keys.

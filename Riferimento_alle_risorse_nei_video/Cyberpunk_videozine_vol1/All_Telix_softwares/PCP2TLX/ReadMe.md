  I wrote this program on a rainy Sunday afternoon because I
  had nothing better to do and wanted an excuse to put off
  my homework.
  Another reason I wrote it was because I really love Procomm
  Plus's Record feature but I like Telix for a communications
  program.


Format: PCP2TLX Infile [Outfile]

Example: PCP2TLX RBBS \TELIX\RBBS

         This example will convert RBBS.ASP to \TELIX\RBBS.SLT


  Infile and Outfile both have to be without an Extension. The
  extentions .ASP and .SLT are assumed for Infile and Outfile
  respectivly.

  PCP2TLX converts scripts taken from the record mode of Procomm
  Plus V1.1+ and converts them to Telix 3.XX format. It requires
  about 64k of free memory and a couple of K of disk space.

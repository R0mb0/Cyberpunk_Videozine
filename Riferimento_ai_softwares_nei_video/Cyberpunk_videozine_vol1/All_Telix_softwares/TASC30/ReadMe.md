What is TASC?
-------------

  TASC is a fully automated Script Generator written in Borland's Turbo
 Basic.  The Code has grown to over 1200 lines, & it is still growing. 
 TASC was designed to make your life with TELIX a whole lot easier. In
 our opinion TELIX is the best communication Software, obviously you do 
 too!  Please Send your Registration into PTel, because TELIX does need
 your support too! NOW, TASC will create a completely interactive SCRIPT
 for PCBoard with a few touch of keys!  It will use logic to figure out
 what you need to do, and how you need to do it! By answering a few
 Quick YES, NO questions you can log-on any PCBoard 12.1, and go to town.
 Just sitback and watch TASC go into action! After creating the Script
 you simply load up TELIX and edit the number you wrote the script for
 and add it in! If you created a stand alone, you run it with the ALT-S
 feature! TASC Should be ran in your TELIX Directory, so you dont have to
 move the Scripts.

Problem Commands? (Help)
~~~~~~~~~~~~~~~~~~~~~~~~

(1)
 
  After executing TASC you will be given the prompt for a file name without
extension.  You must enter a 8 character or less filename with not "."
extension.  The 8 Character or Less filename will have a extension added
to it of .SCR.

(2) 

  Stand alone Operation is explained pretty well in the code, so it should
be fairly easy!, if you do select yes you simply enter the number in your
dialing dir you wish to call.


(3) 

  Logging the call, this will record everything that happened on that call
so you can view it later, it captures to a straight ascii file that can
be view at dos or with your word processor.

(4)

  Multilingual Operation, this is for any bulletin board (PCBoard) supporting
extra languages, usually French. This will automatically choose the default
protocol on the board which is usually English!  If the board asks no
question about what language to use on Log-On, answer NO to this question.

(5)
 
  Ansi Graphics, this should be YES if you have a color graphics card &
Monitor and you want to see IBM COLOR Graphics.  You must also have ANSI.SYS
loaded up in your CONFIG.SYS on boot-up.  If you have monochrome or dont
use the ANSI.SYS Answer NO.

(6)
  
  Quick Log-On, this simply will skip the welcome ANSI or ASCII, this is
used quite often, specially if you want to get automated or you in a real
hurry.  

   (6A) Skip News Msg, this will only be asked if you selected a quick
Log-On. If you answer YES this will skip the information following your
Name & Password Log-On.
 
(7)
 
  Your First Name? this is where you enter your FIRST NAME and only your
first name, this will be sent to the Computer Bulletin Board so they know
who you are.

(8)

  Your Last Name? this goes along with your First Name.  Works the same way.

(9)

  Your Password, this is your SECRET password for logging on, this is entered
after your Name is entered, this will not be displayed to the local terminal
during the call just incase someone is watching!
 
(10)  

  Scan the Messages, this will simply do a Scan when you log-on to see if
there are any new messages (to and from you also!).  If you haven't been
reading the mail, this could take a while.

(11)

  New File Scan, this will do a New file scan since you last called, either
ALL the directories, which could take a while, or just the Upload or New
File directory which usually is very brief.

(12)

  Download a file, this is very self explanatory, note if you do use this
feature it most likely will be only for 1 Call, since you dont want to 
download the same file every call, but this will allow you to download
a unlimited amount of files while never having to touch a key!

(13) 

  Hang-Up at End of Script, this is usually for the STANDALONE scripts
unless you have a full features Script File, This will simply tell the
board your on to log you off, and at the same time it will automatically
Hang-Up!

you must first configure telix protocols to reflect the proper
params.

the settings in the file transfer configuration should look like
this.

external       key   protocol       upload    download    bat or
protocol              name        filename   filename     script

A......         B      B-gsz       gszu        gszd       Batch


at the "Change which setting?" prompt.   select  "A"  and input
the above.

then all that needs to be done is to be sure that gsz.exe and
both .bat files are in the current telix directory.

this setup was working fine with telix 315 on 9/1/91. ENJOY! :-)

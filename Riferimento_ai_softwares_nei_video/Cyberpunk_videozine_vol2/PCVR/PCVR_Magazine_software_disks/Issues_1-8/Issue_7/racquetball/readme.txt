There are 4 packages for the racquetball court. 
All of them are unknown versions and I have no idea which issue they correlate to.
Included in these is 3dpcvrrb.exe is another version with different file sizes
which I pulled off of Chris Hands website (via Wayback).
The exe files are self-extracting archives.

If you really really want the final racquetball program then you should be
able to take one of the 4 packages and reconstruct it using the code listings
from the magazine (tip: copy the text from the OCR'd PDF and then format it).
I don't think any of them are the final versions (by comparing code from
the magazine) but it looks like they all have Sega glasses support so they're
pretty close. Final version had Sega glasses support plus collision.
Thankfully the collision routine is available in the magazine. Happy hacking.

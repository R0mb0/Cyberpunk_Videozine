3DS2PLG.zip - This program accept as input "ascii" files generated by 3D Studio 1.0, and probably 2.0 as well (not tested yet). It borrows heavily from the 3D Studio loading code in RayTracker, a commercial ray tracing program for AutoCAD and 3D Studio models.

DXF2PLG.zip - converts AutoCAD / 3D Studio DXF files to PLG.

GLOBE.zip - This is version 1.0A of Rend Globe. It produces plg files (format 4.0) for use with Bernie Roehl's Rend386. 

MOBIUS.zip - Mobius - Generates a mobius strip .plg file for Rend386

PRISM.zip - PRISM v1.1 by Chris Hand. This simple program can be used to create .PLG files for use with the REND386 libaries and routines.

STARS.zip - Written by Bernie Roehl, November 1992. Generate a star field as a .PLG file.
